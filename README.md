# MyFreeLibrary

**MyFreeLibrary** — это приложение-ридер с возможностью работы с текстовыми файлами. Основная задача проекта — предоставить бесплатный и удобный интерфейс для чтения с возможностью полной кастомизации под пользователя: от редактирования текстов до тонкой настройки шрифтов и визуальных тем.

---

## Стек технологий
* **Vanilla JS (ES6+)** — логика и управление данными.
* **HTML5 / CSS3** — структура и визуальное оформление.
* **LocalStorage** — сохранение библиотеки и настроек пользователя в браузере.

---

## Инструкция по использованию
Приложение работает напрямую в браузере и не требует сложной настройки окружения.

1.  **Установка**: Склонируйте репозиторий на локальную машину.
2.  **Запуск**: Откройте файл `index.html` через любой современный браузер.
3.  **Импорт книг**: Используйте кнопку добавления в интерфейсе для загрузки текстового файла. Система автоматически создаст карточку книги в общем списке.
4.  **Чтение и настройка**: Перейдите в режим чтения, кликнув по карточке. В боковом меню доступны настройки оформления, которые сохраняются автоматически.

---

## Структура кода
Проект разделен на логические модули для удобства поддержки и чистоты архитектуры:
* `data.js` — содержит структуры данных и модели (классы).
* `logic.js` — основные вычислительные процессы (например, алгоритм расчета страниц).
* `ui.js` — работа с интерфейсом и событиями.
